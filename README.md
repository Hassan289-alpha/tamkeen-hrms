# Office Attendance & Leave Management System

A full-stack React.js and Node.js/MongoDB application with role-based access for HR and Employees.

## 🚀 Quick Start Guide

### 1. Open in VS Code
If you haven't already, extract this ZIP file and open the resulting folder in VS Code.

### 2. Run the Backend
1. Open a new terminal in VS Code (`Terminal -> New Terminal`).
2. Navigate to the backend folder:
   ```bash
   cd backend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the `backend` folder and add your MongoDB string:
   ```text
   MONGO_URI=your_mongodb_connection_string
   PORT=5000
   ```
5. Start the server:
   ```bash
   npm run dev
   ```

### 3. Run the Frontend
1. Open a *second* terminal in VS Code.
2. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the React app:
   ```bash
   npm start
   ```

Your browser will automatically open to `http://localhost:3000`.
