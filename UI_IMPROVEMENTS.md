## 🎨 **Design System Overview**

### **Color Palette:**
```
Primary Gradient:  #667eea → #764ba2 (Purple)
Secondary:         #3b82f6 → #2563eb (Blue)
Success:           #10b981 → #059669 (Green)
Warning:           #f59e0b → #d97706 (Amber)
Danger:            #ef4444 → #dc2626 (Red)
Background:        #f8fafc → #e2e8f0 (Light gray gradient)
Card:              #ffffff (White)
Text Primary:      #1e293b (Dark blue-gray)
Text Secondary:    #64748b (Medium gray)
Borders:           #e2e8f0 (Light border)
```

### **Typography:**
- Font Family: Segoe UI, Tahoma, Geneva, Verdana, sans-serif
- Headings: 700 weight, varied sizes (20px → 36px)
- Body text: 400-600 weight, 13px → 16px
- Professional hierarchy with clear visual distinction

### **Spacing:**
- Consistent padding (20px, 30px, 40px)
- Grid gaps (12px, 15px, 20px, 25px)
- Professional margins between sections

### **Effects:**
- **Shadows:** `0 4px 20px rgba(0,0,0,0.05)` to `0 20px 60px rgba(0,0,0,0.2)`
- **Transitions:** 0.3s ease on all interactive elements
- **Hover Effects:** 
  - Buttons: translateY(-2px) with enhanced shadow
  - Cards: Subtle scale and shadow changes
- **Gradients:** Smooth color transitions on backgrounds and buttons
